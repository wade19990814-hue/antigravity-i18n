# antigravity-i18n


Инструмент локализации пользовательского интерфейса для настольного клиента Google Antigravity.

## Статус проекта и поддерживаемые платформы

Этот репозиторий является основным для дальнейшей разработки. Текущая ветка `main` содержит приложение Go/Wails v3 и пока поддерживает **только Windows**. Прежняя кроссплатформенная реализация Node.js/npm отдельно сохранена в [ветке legacy-node](https://github.com/wade19990814-hue/antigravity-i18n/tree/legacy-node); её теги и релизы v1/v2 остаются без изменений.

---

Автономный исполняемый файл, объединяющий современный графический интерфейс, чистый движок Go asar и полные языковые пакеты. Запускается «из коробки» без каких-либо зависимостей от Node.js или библиотек времени выполнения и поддерживает восстановление официальной сборки с точностью до байта в любое время.

---

## Ключевые особенности

- **Один автономный двоичный файл**: автономный исполняемый файл размером ~12 МБ — среда выполнения Node.js, npm или Python не требуется.
- **Двойной режим GUI и CLI**: по умолчанию открывается чистое окно рабочего стола с встраиванием полных подкоманд CLI («применить» / «восстановить» / «статус» / «локали») для создания сценариев и автоматизации.
- **Восстановление с точностью до байта**: перед любыми изменениями автоматически создается чистая резервная копия («app.asar.clean-backup»). При восстановлении восстанавливается архив, побайтно идентичный (проверенный SHA-256) официальному выпуску.
- **Неинвазивный дизайн**: локализуется только пользовательский интерфейс оболочки, собственные меню и диалоговые окна выхода. Редакторы кода (Монако), интегрированные терминалы (xterm) и потоки разговоров ИИ остаются строго нетронутыми.
- **Офлайн и надежность**: отсутствие сетевой активности, отсутствие сбора данных. Оснащен предварительной проверкой синтаксиса JavaScript и откатом транзакций в случае непредвиденных ошибок.

## Загрузка и использование

### Скачать

Загрузите последнюю версию «antigravity-i18n.exe» со страницы «Релиз» и запустите ее напрямую.

### 1. Графический интерфейс (рекомендуется)

Дважды щелкните «antigravity-i18n.exe»:
1. Приложение автоматически определяет папку установки Антигравитации (или нажмите «Изменить местоположение», чтобы указать вручную).
2. Нажмите на предпочитаемый язык (выбор английского восстанавливает официальную сборку).
3. Нажмите «Применить»; инструмент подтверждает завершение процесса, обновляет ресурсы и перезапускает Антигравитацию.

### 2. Интерфейс командной строки

Тот же двоичный файл можно вызвать из терминала:

```powershell
# Check current localization status and backups
antigravity-i18n.exe status

# Install a language pack (Simplified Chinese by default)
antigravity-i18n.exe apply --locale zh-CN

# Restore the official untranslated English version
antigravity-i18n.exe restore

# List all bundled language packs with coverage
antigravity-i18n.exe locales
```

Распространенные варианты:
- `--app-dir <путь>`: вручную укажите каталог установки Антигравитации (или установите через `ANTIGRAVITY_APP_DIR`).
- `--locale <code>`: код целевого языка (например, `zh-CN`, `zh-Hant`, `ja`, `ko`, `de`, `es`, `fr`).
- `--no-restart`: не перезапускать Антигравитацию после установки патча.
- `--force`: пропустить 30-секундное ожидание корректного завершения работы и немедленно завершить процессы.
- `--yes`: отключить запрос подтверждения завершения работы.

## Часто задаваемые вопросы и механика

### 1. Что произойдет после официального обновления Антигравитации?
Официальные обновления перезапишут `app.asar`. Просто повторно откройте этот инструмент и еще раз нажмите «Применить». Инструмент автоматически обновит чистую резервную копию, используя новую официальную версию.

### 2. Переключение и восстановление языка
Вы можете напрямую переключаться между любым языком; инструмент плавно заменяет активные исправления, не требуя предварительного восстановления вручную. Нажатие кнопки «Восстановить официальный английский» возвращает клиент в нетронутое состояние в любой момент.

### 3. Управление файлами резервных копий
- `app.asar.clean-backup`: нетронутая официальная резервная копия, необходимая для восстановления. Не удаляйте вручную.
- `app.asar.bak-*`: исторические снимки с отметками времени, оставленные рядом с архивом. Как только ваша текущая установка будет проверена как стабильная, вы можете безопасно удалить эти файлы, чтобы освободить место на диске.

## Сборка из исходного кода

**Предварительные условия**:
- Перейти 1.26+
- Вейлс v2 CLI

```powershell
# Clone the repository
git clone https://github.com/wade19990814-hue/antigravity-i18n.git
cd antigravity-i18n

# Build both GUI and CLI binaries
.\build.ps1

# Run tests (including end-to-end asar verification)
$env:ANTIGRAVITY_ASAR = "$env:LOCALAPPDATA\Programs\antigravity\resources\app.asar.clean-backup"
go test ./...
```
